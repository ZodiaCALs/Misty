Principles

Four principles, in a fixed order

When two rules pull in different directions, the earlier principle wins. That’s how Misty stays calm without getting in anyone’s way.

1

Access

Everyone can see, reach and use every part of the interface, with any input and at any size.

2

Clarity

Text sits on surfaces solid enough to read, and every state shows in more than colour.

3

Direction

Motion shows where something came from and where it went. Nothing moves only to decorate.

4

Atmosphere

One hue lights a field behind thin glass, so a product feels calm before it feels designed.

One hue

Choose one number. Get every colour.

Accent, field, ink, glass and shadow all come from a single hue in OKLCH. Move the slider and this whole page follows.

250°

Every pair of text and background in the contrast table passes WCAG AA at all 360 hues, in light and in dark. A script checks it, not an eye.

Materials

Four grades of glass, one job each

The field glows behind thin glass, and each grade is a little more solid than the last. When someone asks for less transparency, every grade becomes Cloud and nothing else changes.

Atmosphere only. It never carries text.

Mist

Cards and panels in the flow of the page.

Anything people read for long, and every fallback.

Platforms

Native on every platform

One token file builds a package for each platform. Each package converts colour exactly as browsers do, so a hue chosen on a phone matches the web to the last channel.

platforms/web/misty.cssHTML and CSS

Web
<link rel="stylesheet" href="misty.css">

<html lang="en-GB" style="--m-hue: 250">
  <button class="btn btn--primary" type="button">Save changes</button>
</html>

platforms/appleSwiftUI

Apple
import MistyTokens

let theme = MistyTheme(hue: 250, appearance: .light)

Text("Field notes")
    .foregroundStyle(theme.ink90)
    .padding(MistySpace.s4)
    .background(theme.cloud, in: RoundedRectangle(cornerRadius: MistyRadius.lg))

platforms/androidJetpack Compose

Android
val theme = MistyTheme(hue = 250.0)

Text(
    text = "Field notes",
    color = theme.ink90,
    modifier = Modifier.padding(MistySpace.S4),
)

platforms/windowsWinUI 3, WPF and .NET MAUI

Windows
var theme = new MistyTheme(hue: 250);
var sky = theme.Sky;

var brush = new SolidColorBrush(ColorHelper.FromArgb(sky.A, sky.R, sky.G, sky.B));

platforms/flutterFlutter on any platform

Flutter
const theme = MistyTheme(hue: 250);

Text(
  'Field notes',
  style: TextStyle(color: theme.ink90),
);

platforms/jsAny JavaScript runtime

React Native
import { theme, space, radius } from "./misty-tokens.mjs";

const colours = theme({ hue: 250, appearance: "dark" });
const card = { backgroundColor: colours.cloud, padding: space.s4, borderRadius: radius.lg };

Checked

Specified, measured, tested

Misty is a standard, not a mood board. Every claim on this page can be checked against a numbered requirement or a script.

Every rule has a name

248 numbered requirements, such as LAY-12 and COL-10, each a MUST, SHOULD or MAY. The checklist turns them into a review for a ticket.

Contrast at every hue

Twelve text pairs pass WCAG at all 360 hues, in light and dark. The check runs in a script on every change.

One source, no drift

One token file builds the web, Apple, Android, Windows, Flutter and JavaScript packages, and they agree to the last 8-bit channel.
